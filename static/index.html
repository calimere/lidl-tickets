Lidl ne permet de se connecter que depuis son application mobile : il faut donc récupérer le code de connexion qu'il renvoie. Vous saisissez vos identifiants sur la vraie page Lidl ; le portail ne les voit jamais.

Option 1 – Extension (recommandée) · Chrome, Edge, Brave, Firefox
  1. Téléchargez l'extension et décompressez le zip.
  2. Ouvrez chrome://extensions et activez le mode développeur.
  3. Charger l'extension non empaquetée → choisissez le dossier décompressé.
  4. Rechargez cette page, puis cliquez de nouveau sur « Se connecter à Lidl Plus ».
  1. Installer pour Firefox et acceptez l'ajout, puis rechargez cette page.
  2. Téléchargez l'extension et décompressez le zip.
  3. Ouvrez about:debugging#/runtime/this-firefox → Charger un module complémentaire temporaire… → choisissez le fichier manifest.json du dossier décompressé (à refaire après chaque redémarrage de Firefox).
  4. Rechargez cette page, puis cliquez de nouveau sur « Se connecter à Lidl Plus ».
