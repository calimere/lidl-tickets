Extension Chrome requise

Pour relier votre compte Lidl Plus, une petite extension Chrome capte le code de connexion renvoyé par Lidl (elle ne voit ni votre mot de passe ni vos pages).

  1. Téléchargez l'extension et décompressez le zip.
  2. Dans Chrome, ouvrez chrome://extensions et activez le mode développeur.
  3. Cliquez sur Charger l'extension non empaquetée et choisissez le dossier décompressé.
  4. Rechargez cette page, puis cliquez de nouveau sur « Se connecter à Lidl Plus ».
