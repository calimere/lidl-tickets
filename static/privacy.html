Pour limiter les tentatives de piratage, le nombre d'essais de connexion est compté par adresse IP et par e-mail, uniquement en mémoire : ces compteurs ne sont pas enregistrés.

Base légale et finalités

Les données sont traitées pour vous fournir le service que vous avez demandé (création de votre compte et import de vos tickets). Elles ne servent à rien d'autre : ni publicité, ni revente, ni profilage, ni mesure d'audience.

Combien de temps ?

  • Vos données sont conservées jusqu'à la suppression de votre compte.
  • « Déconnecter Lidl » supprime immédiatement le jeton Lidl.
  • « Supprimer mon compte » efface le compte, les tickets, le jeton et les sessions, sans délai.
  • Les comptes de démonstration (données fictives) sont supprimés après {{TTL_DEMO}} h.

Qui y a accès ?

Personne d'autre que vous et l'éditeur, qui héberge la base sur son propre serveur. Vos données ne sont transmises à aucun tiers. Seule exception technique : les bibliothèques de graphiques sont chargées depuis le CDN jsDelivr, qui voit donc votre adresse IP comme pour toute ressource web.

Le portail contacte Lidl uniquement pour échanger votre jeton et télécharger vos tickets, à votre demande.

L'extension Chrome

Elle n'agit que lorsque vous cliquez sur « Se connecter à Lidl Plus », uniquement dans l'onglet qu'elle ouvre alors. Elle ne lit ni vos pages, ni votre mot de passe, ni votre historique : elle repère seulement le code de connexion renvoyé par Lidl en fin de connexion et le transmet à ce portail. Son code est lisible dans le fichier téléchargé.
